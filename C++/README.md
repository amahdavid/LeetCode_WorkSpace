# C++ Solutions

C++ is used here as one implementation language for algorithms learned through the NeetCode 150.

The priority is not C++ syntax mastery. Start from a language-independent solution, then express that solution using appropriate C++ data structures and idioms.

Existing Arrays & Hashing work includes:

- Contains Duplicate
- Valid Anagram
- Two Sum

When translating a known solution into C++, pay attention to containers such as `unordered_map`, `unordered_set`, `vector`, and the cost characteristics of the operations being used.
