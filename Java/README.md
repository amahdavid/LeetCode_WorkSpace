# Java Solutions

Java is one of the implementation languages used to translate language-independent algorithmic solutions into working code.

The main goal is to preserve the reasoning first, then practice expressing it with Java collections and syntax.

Existing work includes Arrays & Hashing solutions for Contains Duplicate, Valid Anagram, and Two Sum, plus an early Two Pointers solution for Valid Palindrome.

When translating into Java, focus on choosing the right structures such as `HashMap`, `HashSet`, arrays, and lists rather than memorizing syntax mechanically.
