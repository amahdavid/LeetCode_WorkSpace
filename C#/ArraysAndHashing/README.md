# Arrays & Hashing

This is the first topic in the NeetCode 150 study plan.

## What to recognize

Common signals for arrays and hashing problems include:

- Fast lookup or membership checks
- Counting frequencies
- Detecting duplicates
- Mapping one value to another
- Grouping values by a derived key
- Avoiding repeated scans of an array

## Core C# tools

Become comfortable using:

- `Dictionary<TKey, TValue>`
- `HashSet<T>`
- Arrays
- Lists
- String/character iteration
