# TypeScript Solutions

TypeScript is an **optional translation language** in this workspace.

Use it when translating a known solution would reinforce TypeScript fluency for frontend or full-stack interviews. It is not necessary to implement every NeetCode problem here.

The algorithm should be understood before implementation. When translating into TypeScript, focus on expressing the same reasoning clearly while becoming comfortable with structures such as:

- `Map<K, V>`
- `Set<T>`
- arrays
- tuples
- typed helper functions
- interfaces/types when they genuinely improve clarity

The goal is not to turn algorithm practice into TypeScript syntax drills. Use this folder when TypeScript practice adds value beyond the core C#, Java, and Python implementations.
