# JavaScript Solutions

JavaScript is used here to practice translating known algorithmic solutions into a dynamic language.

The goal is to keep the algorithm stable while learning how JavaScript represents the required data structures and operations.

Existing Arrays & Hashing work includes:

- Contains Duplicate
- Valid Anagram
- Two Sum

When translating, focus on structures such as `Map`, `Set`, arrays, and objects, and be conscious of language-specific behavior without letting syntax distract from the underlying solution.
